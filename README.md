# Warringah Golf

A Wii-golf-style game you play in the browser, with your phone as the club.

- `index.html` — the game: course menu, 3D course, scorecard (open on the Mac)
- `lab.html` — Swing Lab: set your full swing, test clubs and putting
- `controller.html` — the club (open on the phone by scanning the QR code)
- `courses/warringah.js` — course data, generated by `tools/build_course.py` from `data/warringah-osm.json`
- `courses/warringah-elev.js` — ground heights, generated by `tools/build_elev.py` from `data/warringah-lidar.json` (Geoscience Australia LiDAR 5 m DEM)

Course map data © OpenStreetMap contributors (ODbL). Elevation © Geoscience Australia (CC BY 4.0). Tree positions traced from Esri World Imagery (`data/warringah-canopy.png`, `tools/canopy.py`). Uses three.js, PeerJS and qrcode-generator (vendored).
